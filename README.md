# Kính Launcher cho TV Casper (Android TV 14)

Launcher nhẹ, giao diện kính trong suốt, thay cho màn hình chính mặc định nặng nề.

- 3 ô lớn: YouTube, VTV Go, FPT Play
- Đồng hồ, ngày tiếng Việt, thời tiết Hà Nội (Open-Meteo)
- Nút Nguồn HDMI, Cài đặt, Tất cả ứng dụng
- Tự chuyển nền sáng (6h–18h) / nền tối
- Hiệu ứng kính giả lập (nền làm mờ sẵn) để không tốn GPU trên chip yếu

## Tải về và cài

Vào mục **Releases** của repo, tải `KinhLauncher-goi-cai-dat.zip`, giải nén và đọc `HUONG-DAN.txt`.

GitHub Actions tự build lại bản mới mỗi khi có thay đổi trên nhánh `main`.
